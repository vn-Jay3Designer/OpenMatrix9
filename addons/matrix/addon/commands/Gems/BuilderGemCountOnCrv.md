## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Size=` | Đường kính đá | 1.5 | 0.3 … 30 |
| `Spacing=` | Khe giữa đá | 0.2 | 0 … 5 |
| `Start=` | Điểm bắt đầu | 0 | 0 … 100 |
| `End=` | Điểm kết thúc | 100 | 0 … 100 |
| `ZOffset=` | Nâng/hạ (Z) | 0 | -10 … 10 |
| `Layout=` | Cách chia | fit | fit, fixed_gap |
| `Orient=` | Hướng mặt đá | plane | plane, outward |
