# Continue Control Point Curve

Vẽ tiếp đường cong điểm điều khiển.

- **Mã lệnh:** `CurveFreeFormContinueCurve`
- **Vị trí:** menu Curve, ô số 42
- **Icon:** `Resources/icons/curve-minimal/CurveFreeFormContinueCurve.svg`
- **Gọi bằng dòng lệnh:** `CurveFreeFormContinueCurve`, `ContinueCurve`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong.
2. Bấm các điểm điều khiển mới, Enter.
