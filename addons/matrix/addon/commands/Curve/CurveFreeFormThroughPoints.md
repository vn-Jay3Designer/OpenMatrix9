# Curve Through Points

Vẽ đường cong qua các điểm đã chọn.

- **Mã lệnh:** `CurveFreeFormThroughPoints`
- **Vị trí:** menu Curve, ô số 26
- **Icon:** `Resources/icons/curve-minimal/CurveFreeFormThroughPoints.svg`
- **Gọi bằng dòng lệnh:** `CurveFreeFormThroughPoints`, `CrvThroughPt`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn các điểm.
2. Type=Interpolate/Polyline.
3. Enter.

## Tuỳ chọn (lệnh phụ)

- Type: đường cong mượt hoặc polyline.
