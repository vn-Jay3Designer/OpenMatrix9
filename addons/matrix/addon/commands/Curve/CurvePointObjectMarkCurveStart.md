# Mark Curve Start

Đặt điểm và mũi tên hướng ở đầu đường cong.

- **Mã lệnh:** `CurvePointObjectMarkCurveStart`
- **Vị trí:** menu Curve, ô số 32
- **Icon:** `Resources/icons/curve-minimal/CurvePointObjectMarkCurveStart.svg`
- **Gọi bằng dòng lệnh:** `CurvePointObjectMarkCurveStart`, `MarkStart`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong, Enter.
