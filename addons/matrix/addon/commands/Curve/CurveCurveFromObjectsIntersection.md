# Intersection

Tạo đường giao giữa các mặt/khối.

- **Mã lệnh:** `CurveCurveFromObjectsIntersection`
- **Vị trí:** menu Curve, ô số 17
- **Icon:** `Resources/icons/curve-minimal/CurveCurveFromObjectsIntersection.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveFromObjectsIntersection`, `Intersect`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn hai mặt/khối trở lên.
2. Enter.
