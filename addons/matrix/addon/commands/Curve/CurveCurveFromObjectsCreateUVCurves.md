# Create UV Curves

Trải phẳng mặt NURBS thành khung UV (và các đường cong nằm trên mặt).

- **Mã lệnh:** `CurveCurveFromObjectsCreateUVCurves`
- **Vị trí:** menu Curve, ô số 24
- **Icon:** `Resources/icons/curve-minimal/CurveCurveFromObjectsCreateUVCurves.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveFromObjectsCreateUVCurves`, `CreateUVCrv`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn mặt (và đường cong trên mặt).
2. Enter.
