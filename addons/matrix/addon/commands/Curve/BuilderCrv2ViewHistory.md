# Curve from 2 Views Builder

- **Mã lệnh:** `BuilderCrv2ViewHistory`
- **Vị trí:** menu Curve, ô số 14
- **Icon:** `Resources/icons/curve-minimal/BuilderCrv2ViewHistory.svg`
