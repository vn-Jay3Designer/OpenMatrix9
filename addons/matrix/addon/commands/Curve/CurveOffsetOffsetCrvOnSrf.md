# Offset Curve on Surface

Offset đường cong nằm trên mặt, kết quả bám mặt.

- **Mã lệnh:** `CurveOffsetOffsetCrvOnSrf`
- **Vị trí:** menu Curve, ô số 19
- **Icon:** `Resources/icons/curve-minimal/CurveOffsetOffsetCrvOnSrf.svg`
- **Gọi bằng dòng lệnh:** `CurveOffsetOffsetCrvOnSrf`, `OffsetCrvOnSrf`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong và mặt, Enter.
2. Gõ khoảng cách.
3. Bấm phía.
