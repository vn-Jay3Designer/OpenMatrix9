# Control Point Curve

Vẽ đường cong theo điểm điều khiển.

- **Mã lệnh:** `CurveFreeFormControlPoints`
- **Vị trí:** menu Curve, ô số 41
- **Icon:** `Resources/icons/curve-minimal/CurveFreeFormControlPoints.svg`
- **Gọi bằng dòng lệnh:** `CurveFreeFormControlPoints`, `Curve`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Bấm các điểm điều khiển.
2. Enter để kết thúc.

## Tuỳ chọn (lệnh phụ)

- Degree, Close, PersistentClose, Undo.
