# Curve Boolean

Hợp / giao / trừ các đường cong kín phẳng.

- **Mã lệnh:** `CurveCurveEditToolsCurveBoolean`
- **Vị trí:** menu Curve, ô số 37
- **Icon:** `Resources/icons/curve-minimal/CurveCurveEditToolsCurveBoolean.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveEditToolsCurveBoolean`, `CrvBoolean`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn các đường cong kín.
2. Mode=Union/Intersection/Difference.
3. Enter.

## Tuỳ chọn (lệnh phụ)

- Mode: kiểu boolean.
- DeleteInput: xoá đường gốc.
