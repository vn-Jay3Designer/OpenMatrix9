# Sketch

Phác thảo đường cong bằng các điểm bấm (Rhino Sketch); OnSurface/OnMesh để vẽ lên mặt hoặc lưới.

- **Mã lệnh:** `CurveFreeFormSketch`
- **Vị trí:** menu Curve, ô số 45
- **Icon:** `Resources/icons/curve-minimal/CurveFreeFormSketch.svg`
- **Gọi bằng dòng lệnh:** `CurveFreeFormSketch`, `Sketch`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Start of sketch.
2. Next point of sketch (Enter để xong).

## Tuỳ chọn (lệnh phụ)

- OnSurface=No.
- OnMesh=No.
