# Extract Wireframe

Lấy khung dây (isocurve / cạnh) của mặt, khối.

- **Mã lệnh:** `CurveCurveFromObjectsExtractWireframe`
- **Vị trí:** menu Curve, ô số 54
- **Icon:** `Resources/icons/curve-minimal/CurveCurveFromObjectsExtractWireframe.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveFromObjectsExtractWireframe`, `ExtractWireframe`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Enter.
