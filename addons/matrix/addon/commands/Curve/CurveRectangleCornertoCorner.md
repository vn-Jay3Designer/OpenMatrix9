# Rectangle

Vẽ hình chữ nhật theo hai góc.

- **Mã lệnh:** `CurveRectangleCornertoCorner`
- **Vị trí:** menu Curve, ô số 4
- **Icon:** `Resources/icons/curve-minimal/CurveRectangleCornertoCorner.svg`
- **Gọi bằng dòng lệnh:** `CurveRectangleCornertoCorner`, `Rectangle`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Bấm góc thứ nhất.
2. Bấm góc đối diện (hoặc gõ dài, rộng).

## Tuỳ chọn (lệnh phụ)

- Center: từ tâm.
- 3Point: theo 3 điểm.
- Vertical: đứng vuông góc CPlane.
- Rounded: bo góc (gõ bán kính).
