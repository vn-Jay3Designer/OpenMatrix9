# Soft Edit Curve

Kéo một điểm trên đường cong, vùng lân cận đi theo mềm mại.

- **Mã lệnh:** `CurveCurveEditToolsSoftEdit`
- **Vị trí:** menu Curve, ô số 55
- **Icon:** `Resources/icons/curve-minimal/CurveCurveEditToolsSoftEdit.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveEditToolsSoftEdit`, `SoftEditCrv`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong, Enter.
2. Gõ khoảng ảnh hưởng.
3. Bấm điểm trên đường cong.
4. Bấm điểm đích.
