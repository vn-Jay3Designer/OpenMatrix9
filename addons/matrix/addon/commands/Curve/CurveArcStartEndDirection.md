# Arc Start End Direction

Vẽ cung tròn từ điểm đầu, điểm cuối và hướng tiếp tuyến.

- **Mã lệnh:** `CurveArcStartEndDirection`
- **Vị trí:** menu Curve, ô số 8
- **Icon:** `Resources/icons/curve-minimal/CurveArcStartEndDirection.svg`
- **Gọi bằng dòng lệnh:** `CurveArcStartEndDirection`, `ArcDirection`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Bấm điểm đầu.
2. Bấm điểm cuối.
3. Bấm hướng tại điểm đầu.
