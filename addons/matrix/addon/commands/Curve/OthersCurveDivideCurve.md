# Divide Curve

Chia đường cong thành các đoạn bằng nhau (đặt điểm).

- **Mã lệnh:** `OthersCurveDivideCurve`
- **Vị trí:** menu Curve, ô số 36
- **Icon:** `Resources/icons/curve-minimal/OthersCurveDivideCurve.svg`
- **Gọi bằng dòng lệnh:** `OthersCurveDivideCurve`, `Divide`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong, Enter.
2. Mode=Count/Length.
3. Gõ số đoạn hoặc độ dài đoạn.

## Tuỳ chọn (lệnh phụ)

- Mode: theo số đoạn hoặc theo độ dài.
