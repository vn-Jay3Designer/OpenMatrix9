# Extend Curve

Kéo dài đầu đường cong theo độ dài.

- **Mã lệnh:** `CurveExtendCurveExtendCurve`
- **Vị trí:** menu Curve, ô số 27
- **Icon:** `Resources/icons/curve-minimal/CurveExtendCurveExtendCurve.svg`
- **Gọi bằng dòng lệnh:** `CurveExtendCurveExtendCurve`, `Extend`, `ExtendCrv`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong, Enter.
2. Type=Line/Smooth, End=End/Start/Both.
3. Gõ độ dài.

## Tuỳ chọn (lệnh phụ)

- Type: kéo thẳng hoặc mượt.
- End: đầu nào.
