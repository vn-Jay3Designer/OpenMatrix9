# Sketch on Polygon Mesh

Vẽ phác trên lưới đa giác.

- **Mã lệnh:** `CurveFreeFormSketchonPolygonMesh`
- **Vị trí:** menu Curve, ô số 47
- **Icon:** `Resources/icons/curve-minimal/CurveFreeFormSketchonPolygonMesh.svg`
- **Gọi bằng dòng lệnh:** `CurveFreeFormSketchonPolygonMesh`, `SketchOnMesh`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn lưới.
2. Bấm các điểm, Enter.
